This assignment explores how house prices vary across Nairobi. The first part estimates prices for the whole city, including places with no sales data, by blending nearby known prices, with closer houses weighted more. The notebook tests how accurate this is by predicting each house’s price from all the others. The second part asks why prices differ by location. It tests whether population, distance to roads and distance to parks affect prices, and it lets those effects change from one neighbourhood to the next. Maps show where each factor matters most and where the model fits best. A final check confirms the model’s errors aren’t clustered spatially, which would signal that something is missing.
We analyse housing prices in Nairobi using two spatial methods, with data loaded from a GeoPackage. First it builds a 300×300 interpolation grid over the city boundary. It then runs Inverse Distance Weighting (IDW) with a cKDTree nearest-neighbour search (k=12, power=2), masks cells outside Nairobi, and maps the predicted price surface. It validates the IDW surface with leave-one-out cross-validation, reporting RMSE, MAE and R², and maps the residuals. The second half merges housing points with population, distance-to-roads and distance-to-parks layers. It collapses duplicate locations and fits a Geographically Weighted Regression (GWR) on log price using the mgwr package, with an adaptive bisquare kernel and AICc bandwidth selection. The outputs are local coefficient maps, significance maps based on t-values, and a local R² map. Validation includes Moran’s I on the residuals to test for spatial autocorrelation, plus an observed-versus-predicted plot.
